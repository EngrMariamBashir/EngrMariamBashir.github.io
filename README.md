# Mariam Bashir Tutoring Website

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `mariam-tutoring`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Your site will appear at a URL similar to `https://YOUR-USERNAME.github.io/mariam-tutoring/`.

## Important edits before publishing
- In `script.js`, replace `YOUR_EMAIL_HERE` with your actual email address.
- In `index.html`, replace the `PKR ___ / hour` placeholders with your prices.
- Replace the sample testimonials with genuine testimonials.
- Update subjects and qualifications as desired.

The profile image is stored as `mariam-profile.png`.
